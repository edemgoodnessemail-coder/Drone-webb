How to Push and Publish to GitHub Pages

  1. Save this single file as index.html in a new folder on your computer.
  2. Open your terminal or command prompt inside that folder and initialize a Git repository:
    git init && git add index.html && git commit -m "Initial commit: Drone Photo Gallery"
  3. Create a new repository on GitHub.com (e.g., named drone-gallery).
  4. Link your local repository and push your code:
    git remote add origin https://github.com/YOUR-USERNAME/drone-gallery.git
    git branch -M main
    git push -u origin main
  5. Go to your GitHub Repository settings → Pages, select the main branch as the source, and save! Your app will be live at https://YOUR-USERNAME.github.io/drone-gallery/.
